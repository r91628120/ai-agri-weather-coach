FIELD MANAGEMENT CENTER

🌾 農地管理中心

Google Maps 網址只負責找到農地附近位置；真正用於衛星 NDVI、氣象與 Farm Memory 的核心資料， 是農民沿著實際田區畫出的完整邊界。

① 找到農地位置
② 畫出農地範圍
③ 檢查並儲存
可解析包含 @緯度,經度、q=緯度,經度、 query=緯度,經度 或 !3d緯度!4d經度 的完整網址。 maps.app.goo.gl 短網址需要先在 Google Maps 開啟，再複製展開後的完整網址。
地圖與資料來源說明：Esri 圖磚只用於位置參考與繪製農地；紅色 Polygon 邊界的經緯度座標才會送往 CDSE 搜尋 Sentinel-2 L2A 觀測資料。Esri 底圖不參與 NDVI 計算。
步驟一：先貼上 Google Maps 完整網址或輸入經緯度定位。
步驟二：按「畫出農地範圍」，沿著田區四周依序點選，最後點回起點完成。
為什麼一定要畫邊界？
Google Maps 圖釘只表示「這附近」，無法指出到底是哪一塊田。 Process API 與 Statistical API 需要完整 Polygon，才能只分析該田區的 NDVI， 避免把道路、水溝、池塘或鄰田一起算進去。

SATELLITE NDVI

🛰️ 衛星 NDVI 田區判讀基礎版

本版已完成真實 Sentinel-2 L2A NDVI 統計與 Process API 彩色 PNG， 可檢視田區植生差異、透明遮罩、觀測資訊與地圖定位覆蓋。 NDVI 歷史趨勢仍屬後續版本，相關端點明確回傳 501 Not Implemented。

Sentinel-2 觀測搜尋提供日期與雲量；統計 API 顯示平均值等指標，Process API 則以相同 B04、B08 與 dataMask 產生具透明通道的 NDVI 彩色 PNG。NDVI 歷史趨勢為後續版本。
